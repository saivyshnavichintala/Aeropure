Missing values can reduce the quality of machine learning models. Numerical missing values are handled using median imputation, while categorical missing values are handled using mode imputation.

11. Min-Max Normalization

Min-Max normalization transforms values to a fixed range, normally from 0 to 1.

X' = (X − Xmin) / (Xmax − Xmin)

12. Standardization vs Min-Max Normalization

Both techniques scale numerical features, but they produce different numerical ranges.

Technique Typical Range Main Purpose
Standardization Approximately centered around 0 Useful when mean and standard deviation are important.
Min-Max 0 to 1 Useful when a fixed numerical range is required.
