5 Entropy

Entropy measures the impurity or uncertainty in a dataset.

H(S) = -Σ pᵢ log₂(pᵢ)

Example Calculation

Total samples = {{ result.concept_calculations.example_total }}

High = {{ result.concept_calculations.high_count }} and Low = {{ result.concept_calculations.low_count }}

Therefore:

H(S) = - ({{ result.concept_calculations.high_probability }} log₂({{ result.concept_calculations.high_probability }})) - ({{ result.concept_calculations.low_probability }} log₂({{ result.concept_calculations.low_probability }}))

Entropy = {{ result.concept_calculations.entropy }}

6 Information Gain

Information Gain measures how much uncertainty is reduced after splitting the dataset.

IG = H(parent) - Σ (|child| / |parent|) H(child)
Information Gain = {{ result.concept_calculations.information_gain }}

A higher Information Gain generally indicates a better split for ID3.

7 Gini Impurity

Gini impurity measures the probability of incorrectly classifying a randomly selected sample.

Gini = 1 - Σ pᵢ²
Gini = {{ result.concept_calculations.gini }}

CART commonly uses Gini impurity for classification.

8 Gain Ratio

Gain Ratio normalizes Information Gain using Split Information.

Gain Ratio = Information Gain / Split Information
Split Information = {{ result.concept_calculations.split_information }}

Gain Ratio = {{ result.concept_calculations.gain_ratio }}

C4.5 uses Gain Ratio to select attributes.

9 ID3

ID3 stands for Iterative Dichotomiser 3.

ID3 uses Entropy and Information Gain to choose the best split.

Steps:
  1. Calculate entropy.
  2. Calculate Information Gain for each feature.
  3. Select the feature with maximum Information Gain.
  4. Split the dataset.
  5. Repeat recursively.

10 C4.5

C4.5 is an extension of ID3. It uses Gain Ratio instead of only Information Gain.

  • Handles continuous attributes.
  • Can handle missing values.
  • Uses pruning.
  • Uses Gain Ratio.

The implementation here uses an entropy-based sklearn Decision Tree as a practical C4.5 approximation; sklearn does not provide a literal C4.5 implementation.

11 CART

CART means Classification and Regression Trees.

  • Classification commonly uses Gini impurity.
  • Regression commonly uses MSE.
  • CART creates binary splits.
Gini = 1 - Σ pᵢ²

12 Tree Construction

  1. Start with the complete dataset.
  2. Calculate impurity.
  3. Evaluate possible splits.
  4. Select the best split.
  5. Create child nodes.
  6. Repeat recursively.
  7. Stop when a stopping condition is reached.
  8. Assign predictions to leaf nodes.

13 Overfitting

Overfitting occurs when a decision tree becomes too complex and learns noise from the training data instead of general patterns.

  • Very deep tree.
  • Very high training accuracy.
  • Lower test accuracy.
  • Poor generalization.

14 Pruning

Pruning removes unnecessary branches from a decision tree to reduce overfitting.

Pre-Pruning

  • max_depth
  • min_samples_split
  • min_samples_leaf

Post-Pruning

Cost-complexity pruning can be controlled using ccp_alpha.

15 Regression Trees

Regression Trees predict a continuous numerical value instead of a class.

MSE = (1/n) Σ(yᵢ - ŷ)²

The leaf generally predicts the mean target value of samples reaching that leaf.

Common evaluation metrics: MSE, RMSE, MAE and R².

16 Random Forest

Random Forest is an ensemble of multiple decision trees.

  • Uses bootstrap samples.
  • Uses random subsets of features.
  • Trees are trained independently.
  • Final classification uses voting.

17 AdaBoost

AdaBoost builds weak learners sequentially. Misclassified observations receive more attention in later rounds.

αₜ = 1/2 ln ((1 - εₜ) / εₜ)

where εₜ is the weighted error of the weak learner.

The final prediction is a weighted combination of the weak learners. It is not produced by one final tree.

18 Gradient Boosting

Gradient Boosting builds trees sequentially. Each new tree attempts to reduce the errors of the previous model.

Fₘ(x) = Fₘ₋₁(x) + ηhₘ(x)

where η is the learning rate and hₘ(x) is the new tree.

19 XGBoost

XGBoost is an optimized implementation of gradient boosting using decision trees.

It adds regularization to control model complexity.

Objective = Loss + Ω(model)

XGBoost combines the predictions of many trees. There is no single final tree.

20 LightGBM

LightGBM is a fast gradient boosting framework designed for efficient learning on large datasets.

  • Histogram-based learning.
  • Leaf-wise tree growth.
  • Fast training.
  • Efficient memory usage.

31 Conclusion

Decision Trees classify PM2.5 into low and high air-quality classes using feature-based splits. Entropy and Information Gain are associated with ID3, Gain Ratio with C4.5, and Gini impurity with CART.

Random Forest, AdaBoost, Gradient Boosting, XGBoost and LightGBM improve prediction by combining multiple decision-tree learners.

The best model is selected based primarily on F1 score, followed by ROC-AUC and Log Loss.
